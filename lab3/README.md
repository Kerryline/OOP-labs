# Работа 3 — Класс Matrix

Класс `Matrix` — матрица целых чисел произвольной размерности с динамическим
выделением памяти (`int**`). Инкапсулирует данные: поля `data_`, `rows_`,
`cols_` доступны только методам класса.

## Возможности класса

- 3 конструктора: пустая матрица 0×0, единичная квадратная `Matrix(n)`,
  матрица `rows × cols`, заполненная нулями;
- деструктор освобождает память в обратном порядке (строки, затем массив указателей);
- `get` / `set` с проверкой индексов (исключение `std::out_of_range`);
- `inputFromKeyboard`, `fillRandom`, `print`, `sum`, `getRows`, `getCols`;
- `transpose()` (домашнее задание).

## Сборка и запуск

```bash
g++ -std=c++17 -Wall -Wextra main.cpp Matrix.cpp -o lab3
./lab3
```

## Что демонстрирует программа

Создание матриц всеми тремя конструкторами, заполнение по формуле `i * j`,
случайное заполнение, ввод с клавиатуры, сумму элементов, работу исключений
(отрицательная размерность и выход за границы), транспонирование и копирование.

## Особенности реализации

- Отрицательная размерность → `std::invalid_argument` до выделения памяти;
- Нулевая размерность → матрица пустая (0×0), память не выделяется, деструктор
  корректно работает с `data_ == nullptr`;
- `new int[cols]{}` — скобки в конце инициализируют элементы нулями;
- Константные методы (`get`, `print`, `sum`, `getRows`, `getCols`) не меняют объект;
- `explicit` у конструктора с одним параметром запрещает неявное `Matrix m = 5`;
- Копирующий конструктор делает глубокое копирование (выделяет новую память
  и копирует значения), поэтому `Matrix mm = m3` не приводит к двойному
  `delete[]`; оператор присваивания добавляется в Работе 4.
